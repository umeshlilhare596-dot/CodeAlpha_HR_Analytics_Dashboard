HR Analytics Dashboard

Project Overview

This project analyzes employee data using Microsoft Power BI to support HR decision-making.

Objectives

- Analyze employee recruitment and workforce distribution.
- Track active employees and employee turnover.
- Analyze employee satisfaction and performance.
- Support hiring and workforce planning.

Tools Used

- Microsoft Power BI
- DAX Measures
- Data Visualization

Key Results

- Total Employees: 15
- Active Employees: 12
- Employees Left: 3
- Employee Turnover Rate: 20%

Visualizations

- Employees by Department
- Employee Satisfaction by Department
- Active vs Left Employees

Data Note

This project uses fictional sample data for demonstration purposes. The dashboard does not represent actual company employees.
